# 백엔드 신입 필독 20선

백엔드 개발자로 첫 취업을 준비하거나 입문한 분을 위한 큐레이션입니다.
이 순서대로 읽으면 면접과 실무 모두 단기간에 커버할 수 있습니다.

---

## 1단계 — 언어와 JVM (1–5편)

이 단계에서는 Java가 어떻게 동작하는지 내부 구조를 파악합니다.

1. [JVM 구조 및 메모리 관리](../Language/Java/JVM%20관련/JVM%20구조%20및%20메모리%20관리.md)
   — Heap, Stack, Metaspace 구분과 GC 흐름. 면접 단골 주제.

2. [JVM Options and Memory Management](../Language/Java/JVM%20관련/JVM_Options_and_Memory_Management.md)
   — `-Xmx`, GC 튜닝 옵션. 실무에서 처음 만나는 설정.

3. [객체지향 프로그래밍 (OOP) — Marker Interface](../Language/Java/객체지향%20프로그래밍%20(OOP)/interface/Marker_Interface.md)
   — 마커 인터페이스 패턴. 설계 언어를 배우는 첫 걸음.

4. [ES6 Class](../Language/JavaScript/09_ES6_및_고급문법/ES6%20Class.md)
   — 백엔드와 함께 다루는 Node.js 비교 관점.

5. [Interface Deep Dive](../Language/TypeScript/타입%20및%20타입%20정의/Object%20Types/Interface_Deep_Dive.md)
   — TypeScript 인터페이스 심화. API 설계 시 즉시 활용 가능.

---

## 2단계 — 네트워크와 HTTP (6–10편)

백엔드의 핵심 교통 레이어. 이 5편을 모르면 API 디버깅이 막힌다.

6. [HTTP](<../Network/7 Layer/Application Layer/Http/HTTP.md>) *(검색: HTTP 기초)*
   — Request/Response 구조, 헤더, 상태 코드.

7. [MacAddress](../Network/7%20Layer/Data%20Link%20Layer/MacAddress.md)
   — L2 계층 이해. 서버 네트워크 트러블슈팅 기초.

8. [SSH](../DevOps/Linux/보안/SSH.md)
   — 개발자 필수. 키 기반 인증과 포트 포워딩.

9. [네트워크 관리](../DevOps/Linux/네트워크/네트워크_관리.md)
   — `netstat`, `ss`, `tcpdump` 실전 사용법.

10. [네트워크 트러블슈팅](../DevOps/Linux/네트워크/네트워크_트러블슈팅.md)
    — 연결 끊김, 타임아웃 원인 분석 실무 시나리오.

---

## 3단계 — 데이터베이스 (11–14편)

RDBMS를 실무 수준으로 이해하는 핵심 4편.

11. [RDS](../Cloud/AWS/Database/RDS.md)
    — 관리형 DB 기초. EC2 직접 운영과의 차이.

12. [Aurora DB](../Cloud/AWS/Database/Aurora_DB.md)
    — Aurora 아키텍처와 Multi-AZ 동작.

13. [인덱스 가능성](../DataBase/RDBMS/인덱스_가능성.md)
    — 어떤 컬럼에 인덱스를 걸어야 하는가. 실무 빈출.

14. [컬럼 접미 패턴](../DataBase/RDBMS/Column_Suffix_Pattern.md)
    — 협업 시 컬럼명 규칙. 코드 리뷰에서 바로 써먹는 지식.

---

## 4단계 — 클라우드 입문 (15–17편)

AWS 주요 서비스 3종. 이것만 알면 첫 프로젝트 인프라 투입 가능.

15. [EC2](../Cloud/AWS/Compute/EC2.md)
    — 인스턴스 유형, 구매 옵션, 스토리지 연결.

16. [ECS](../Cloud/AWS/Containers/ECS.md)
    — 컨테이너 오케스트레이션 입문. Fargate 모드 포함.

17. [VPC](../Cloud/AWS/Network/VPC.md)
    — 서브넷, 라우팅, 보안 그룹. 클라우드 네트워크의 뼈대.

---

## 5단계 — 아키텍처와 실무 역량 (18–20편)

코딩에서 설계로 넘어가는 마지막 단계.

18. [CI/CD Pipeline](../DevOps/CI_CD/CI_CD_Pipeline.md)
    — 배포 파이프라인 구축. GitHub Actions 기준.

19. [Prometheus & Grafana](../DevOps/Monitoring/Prometheus_Grafana.md)
    — 모니터링 기초. 장애 대응의 시작.

20. [Infrastructure Design Principles](../DevOps/Principles/Infrastructure_Design_Principles.md)
    — 확장성, 가용성, 비용 균형. 설계 면접 준비.
