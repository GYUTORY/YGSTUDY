# 캐싱 허브

## 이 주제를 언제 찾게 되는가

- 동일 데이터를 반복 조회하는 DB 부하를 줄이기 위해 캐시 레이어를 처음 도입할 때
- 캐시와 DB 사이의 데이터 불일치(Cache Invalidation) 문제를 해결해야 할 때
- Redis를 캐시로 쓸 때 TTL·Eviction Policy를 어떻게 설정해야 할지 고민될 때
- MSA 환경에서 서비스가 여럿일 때 캐시 일관성을 어떻게 유지할지 설계할 때
- NestJS Cache Module이나 Node.js 멀티레벨 캐시를 구성할 때

## 읽는 순서

1. **캐싱 전략** — 여기까지 읽으면 Cache-Aside가 왜 가장 많이 쓰이는지, Write-Through와의 트레이드오프를 이해한다
2. **Redis Cache Strategy** — Redis를 캐시로 쓸 때 Eviction Policy와 Hot Key 문제를 다루는 방법을 익힌다
3. **API 캐싱** — HTTP 레이어와 CDN에서의 캐싱으로 범위를 넓힌다
4. **분산 캐싱 패턴** — 여러 서비스가 캐시를 공유할 때 생기는 정합성 문제를 해결하는 아키텍처를 설계한다
5. **멀티레벨 캐시 / Node Cache Advanced** — 로컬 캐시와 분산 캐시를 조합한 심화 구성으로 마무리한다

## 아직 없는 것

- Cache Stampede(Dog-piling) 방지 패턴 전용 문서
- CDN Cache Purge/Invalidation 전략 (CloudFront 등 실전)
- 캐시 웜업(Warming) 전략 문서
- 세션 캐시와 데이터 캐시의 분리 설계 가이드
- Valkey로 Redis를 대체할 때의 마이그레이션 체크리스트
